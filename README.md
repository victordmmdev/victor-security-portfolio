# Victor Magaldi — Security Portfolio

Site estático que apresenta minha trajetória em tecnologia, meu direcionamento para Red Team e projetos verificáveis de cybersecurity.

## Princípios do conteúdo

- Somente competências e experiências sustentadas por currículo ou projetos públicos.
- Projetos com links diretos para código, documentação e validação.
- Sem métricas fictícias de ameaças, vulnerabilidades ou experiência.
- Sem trackers, formulários ou coleta de dados.

## Execução local

```bash
python -m http.server 8000
```

Abra `http://127.0.0.1:8000`.

## Tecnologias

HTML semântico, CSS responsivo, efeitos 3D acessíveis e JavaScript sem framework. O projeto utiliza canvas para a rede de fundo e a esfera tridimensional, inclinação por ponteiro nos cards e respeita `prefers-reduced-motion`.
